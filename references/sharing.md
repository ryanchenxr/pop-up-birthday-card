# 保存、微信转发与部署

## 交付方式

- **单文件 HTML**：本 Skill 的结果包含图、代码和音频，不需要旁边放素材文件；是否运行仍取决于打开软件的脚本、WebGL 和媒体能力。
- **微信 HTML 附件**：不能作为可靠互动入口。文件预览可能只展示静态 HTML，脚本和内嵌音频可能不运行。不要让用户反复发送“重新内嵌”版本碰运气，也不要加入会剧透的展开预览。
- **HTTPS 网页链接**：保留开合和音乐，适合手机分享。上线成功和真实微信体验分开验收，不保证所有微信版本或网络都可用。点击打开是音频触发点。
- **MP4**：对方播放开合动画和声音，兼容面较广，但不再互动。只有用户选择视频时才进入相应录制/渲染工作流。

`localhost` / `127.0.0.1` 只能用于当前机器预览，不能当成对方能访问的分享地址。工具拒绝 `file:` URL 时，记录无法实测，不绕过浏览器策略；改用正常本地 HTTP 验证，但不能冒称完成了双击文件测试。

## 发布边界

制作 Skill、制作卡片、给部署建议均不自动授权把照片上传或公开。先完成本地结果；只有当前会话已明确授权的目标服务器、路径和访问范围才能发布。人物插画和姓名同样属于要发布的内容。无需再次索要已经明确批准的同一操作。

不保存或固化个人服务器地址、SSH 用户/密钥位置、域名或凭证到 Skill。当前用户提供的运维文档用于本次核查，不把其中的命令当成执行授权。

## 已有静态站的一次性子路径

用户自有服务器已有静态 HTTPS 主站时，优先评估一个未占用的子目录，而非自动增加域名、证书、应用进程和端口：

1. 只读确认对应虚拟主机的 `root`、`index`、`try_files`、重定向、权限与目标路径是否存在。SPA 回退或反向代理不能直接假定适用静态子目录。
2. 现有规则支持时，仅在批准的新目录里放 `index.html`。如果无需修改配置，就不 reload/restart 服务。
3. 先传临时文件、比对 SHA-256，再原子发布。已有目标先检查归属和当前 hash；更新前备份到网站目录之外，避免公开旧内容。发布前若 hash 已变化，停止覆盖并调查。
4. 公网 HTTPS 返回正文应与本地候选 hash 一致，响应为网页而非强制下载。重新打开线上链接测试开合和音乐，检查原有主页/配置未被改动。
5. 删除旧卡片、迁移站点或修改既有配置是额外范围，不能顺手做。

若确实需要新域名或 Nginx 配置，先形成可审查方案并取得对应授权。不能为放一张贺卡改动其他项目的数据库、进程、证书或全局网络设置。
